## 执行权限

新建本地可写预览保存内部 `localGitWrite` 权限快照；仅传给本地写 worker。只读、快照及旧本地运行不自动增加权限。旧记录脚本保存、普通恢复均保持原范围；需要新能力时按同一脚本另建预览。标记进入完整控制字段，不由脚本参数或任意路径输入授予。

Adapter 只解析原项目内的真实 `.git`，核对实际 Git 根目录和 common dir 均在该元数据目录内，记录项目及元数据目录的设备、inode 身份。线程启动及 turn 派发前再次核对；项目外、共享或符号链接元数据不扩大权限，普通源码编辑仍可用。`.agents`、`.codex` 不因 Git 写入而自动开放。

原生 App Server 在线程响应中只返回额外 writable roots，线程 cwd 作为隐含工作根目录。校验按确认后的 cwd 与返回 roots 的有效集合进行，仍严格拒绝外部目录、缺少必要 Git 根、重复根或目录身份变化；发送 turn 使用同一权限集合。没有关闭沙箱，也没有请求失败后扩大任意根目录。
