## 五项视觉核对

- **字体与排版**：保留 Codex 的字体、字号、行高与字重变量。标题、正文和次要文字层级清楚，长节点名有界换行，组名有省略保护；默认 100% 可阅读，用户可缩放总览。
- **布局与间距**：桌面为工具栏、进度摘要、控制流画布及右侧非模态过程侧栏；窄屏侧栏改成可关闭的独立面板。工具栏换行，无页面级横向溢出。宽流程在图内横向和纵向滚动。
- **颜色与 tokens**：运行、成功、失败、停止状态继续使用宿主语义变量；未进入分支和计划路径保留中性虚线。选中状态与运行状态分开，不把未知路径渲染成已完成。
- **图形与资产**：复用现有图标库和纹理。菱形、连接线、汇合点、循环边均由真实结构数据生成，属于功能图表；没有把生成的整张概念图嵌入产品，也没有新增近似图标替代现有资产。
- **文案与状态**：显示实际条件、已观测循环轮次和调用记录。最大轮次未知时不虚构 3 轮；旧运行没有路径事件时保持计划态；路径截断时不把旧判断作为当前分支。历史结果与本轮缓存复用明确区分。

## 交互验证

1. 点击正在运行的修复节点：右侧显示真实简要过程，图仍可操作。
2. 切换“开发日志”：有界日志可读取，保持节点与执行尝试关联。
3. 点击条件节点：显示真实“否”的判断及时间；结构节点不启动 worker。
4. 关闭侧栏：焦点恢复原条件按钮；Esc 可关闭非模态侧栏。
5. 执行设置仍显示实际模型目录、默认设置和执行范围；更多菜单仍含差异、保存工作流库、删除和刷新，Esc 可关闭。
6. 在临时运行上实际停止，再确认恢复预览：6 个有效节点复用、1 个节点重跑。恢复后同一修复任务具有第 1 次已中断和第 2 次运行中尝试；切换两者显示各自状态，返回最新尝试后不混入旧错误。
7. 缩小、重置和适应窗口均改变实际缩放；“适应窗口”改为使用未缩放尺寸，避免结果依赖先前 zoom。
8. 窄屏用真实鼠标滚轮操作：图内 `scrollTop` 从 0 增加至 203。关闭侧栏后工具栏可访问，根 `scrollWidth = clientWidth`。
9. 430 × 932 下侧栏关闭按钮可见，底部操作位于视口内；长内容在侧栏内部滚动。
10. 检查浏览器 error/warn 日志：为空。

## 接受的差异与限制

- 实现继承 Codex 字体和语义色，不把概念图的具体绿色、蓝色与字号写死。
- 节点数、文本、循环内部结构和控制指令由脚本决定，因此不承诺任意脚本都与示意图布局逐像素相同。复杂表达式、动态区域、显式标签跳转及未关联调用保留说明和实际任务回退。
- 此次验证证明真实流程引擎配替身 worker 的 UI 交互；不替代真实模型验收、原生宿主项目归属或新版本加载核对。
- 残余 P3：大型图缩放后仍可进一步优化文本密度及循环内折叠体验。当前没有阻断使用的 P0/P1/P2 问题。
