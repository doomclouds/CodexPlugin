# Workflows 0.5.10 验证记录

## 问题与修复

主下拉框只显示当前运行和工作流库；选择空项或库定义会清除当前运行，项目的其他运行没有进入下拉列表，造成工作流消失的假象。本次改为按“本项目运行”和“工作流库”分组列出，运行包含状态、创建时间和短 ID。运行、定义和分页使用不同选项值；占位项不可选。切换仅读取已有详情，不创建、恢复或执行。

摘要加载期间运行与库定义不会同时选中；切回运行会作废旧的定义读取请求。完整详情读取失败仍禁止执行、修改和应用，但可选其他记录。较多记录可在下拉框加载更多摘要，不批量读取完整详情。

另修复完整列表已确认记录不存在时，面板仍永久保留所选旧记录的问题。完整摘要列表会移除缺失记录；分页中未出现的已选记录单独读取详情，读取失败保持操作禁用。轮询期间刚创建的新运行继续保留，避免旧列表响应丢弃新记录。
