# Workflows 0.11.0

复杂分支、嵌套循环和子流程改用 X6 画布与 ELK 自动布局。执行仍由 0.10.0 的结构化定义和持久状态机负责，画布使用服务端投影，不重新推测执行关系。

## 变化

- 条件、并行、循环回边、汇合与子流程使用明确的层级、端口和连线；分支优先显示定义中的可读标签。
- 支持容器折叠、缩略图、滚轮平移、缩放、定位选中/当前节点及键盘导航。较大流程默认保持可读字号。
- 状态、选择和轮次刷新只更新属性，保留节点位置与用户视口。结构和字体变化才重新布局。
- 节点与连线按实际宿主字体测量，沿用宿主明暗主题。布局 Worker 和资源全部包含在运行包中，不依赖 CDN 或新增产品 Node 服务。
- 修复折叠或端口变化后连线消失、旧 Worker 迟到错误终止新任务，以及侧栏展开后定位使用旧宽度的问题。
- 修复切换节点/尝试时旧日志正文错挂、暂停等操作丢失查看轮次、重连后旧连接错误不消失的问题。同主体后台日志刷新不会反复清空正文。

## 验证与边界

发布前执行类型检查、构建、独立包加载、可移植性及完整测试；实际浏览器覆盖多路条件、并行、双层循环、异常收尾、固定/动态子流程、暂停恢复、轮次日志、折叠和字号变化。

开发预览的活动明确为替身，不调用真实模型或用户工具。发布安装后，使用安装包单独核对真实 worker；安装成功与当前 Codex 聊天加载新版分别报告。详细工程证据见同目录 `rendering-verification-0.11.0.md`，这些工程文档不是发布 Skill 的依赖。

0.11.0 沿用 0.10.0 的 structured-v1 存储格式；0.9.x 及之前的脚本格式仍不兼容，也不会被自动迁移或删除。升级不删除用户定义、运行或原项目改动。

发布沿用本仓库的 GitHub `main` 市场源；从该源刷新并安装，不从开发目录复制插件。
