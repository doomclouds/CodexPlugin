# Workflows 0.5.1 验证记录

## 删除指纹修复

真实 MCP 调用复现：运行停止、版本和文件清单均未变化，删除预览允许清理，紧接着的执行却返回 `preview_changed`。连续读取 Codex 有效配置时，服务及嵌套字段的对象键顺序不同；按原始 JSON 计算的摘要变化，递归排序对象键后的摘要一致。

修补只规范有效配置摘要的对象键顺序，保留配置值和数组顺序。运行版本、文件清单与引用检查不变；命令、环境值、参数顺序或工作区引用真实改变，旧预览仍不能删除。配置只保存摘要，不向调用方输出私密值。

通过修补后的正式 MCP stdio 入口执行实际清理：四条现存运行全部删除，累计 3180 个文件、109655427 字节。每条运行均使用新预览指纹，返回完整成功、无剩余对象。文件系统确认运行目录、运行锁和删除事务不存在，当前桌面聊天的工具也返回空运行列表。保存定义库原本为空，随包发布的内置定义保留。原项目 Git HEAD 和工作区状态、用户配置文件摘要在清理前后保持一致。

## 主题修复

统一原生下拉选项与选项组的背景、文字及禁用颜色，并继承宿主字体字号。占位符、禁用输入框、复选框和单选框采用相同的宿主语义颜色。宿主只提供背景变量时，由明确的不透明背景推导原生控件主题；显式宿主主题始终优先。
