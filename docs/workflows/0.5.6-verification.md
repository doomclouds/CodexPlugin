维护步骤新增可选的 `protectedPaths`，以本次工作区内的相对目录预声明必要范围，例如 `.agents/skills`。仅允许 `.agents`、`.codex` 及其内部现存真实目录；拒绝越界、绝对路径、控制字符、通配符、链接、缺失目录和非目录。默认不新增任何保护目录授权。

声明经过 preview、update、保存定义及面板往返，保留在对应步骤；参与现有执行范围与任务指纹。保留工作区后修改权限须新建预览。引擎重新核对运行自有目录、独立 Git 元数据和源基线，仅将声明传给对应 operation。适配器在命令启动前和每次重试前重新检查真实目录，再加入原生 command/exec 的 writableRoots。网络、临时目录、其他保护目录及原项目权限不变，agent worker 不接收此字段。

面板在执行范围和维护摘要展示“步骤 → 授权目录”，无需手工编辑脚本。参数和声明仍由 Agent 生成。

## 删除路径别名

首次真实沙箱集成的维护和边界检查通过，但清理因 macOS 的 `/var` 与 `/private/var` 别名被误判为外部工作区。修复只从经过 `ownedDirectory` 验证的自有运行目录派生 canonical 工作区候选，不通过解析记录提供的外部路径来建立归属。

MCP 配置和其他运行引用同时检查配置路径与 canonical 路径。部分删除中运行目录已不存在时，仍从受信任的数据根目录和运行 ID 派生候选，以免遗漏尚未解除的引用。自有 workspace 的符号链接、记录提供的外部路径和外部别名仍阻止删除。
