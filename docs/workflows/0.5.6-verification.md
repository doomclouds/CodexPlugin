## 删除路径别名

首次真实沙箱集成的维护和边界检查通过，但清理因 macOS 的 `/var` 与 `/private/var` 别名被误判为外部工作区。修复只从经过 `ownedDirectory` 验证的自有运行目录派生 canonical 工作区候选，不通过解析记录提供的外部路径来建立归属。

MCP 配置和其他运行引用同时检查配置路径与 canonical 路径。部分删除中运行目录已不存在时，仍从受信任的数据根目录和运行 ID 派生候选，以免遗漏尚未解除的引用。自有 workspace 的符号链接、记录提供的外部路径和外部别名仍阻止删除。
