## 安全与恢复边界

删除先事务预留目标，阻止并发启动；关联运行不按分页截断。清理只拥有插件数据，保留原项目。未知写入先检查真实效果与指纹，再原子提交证据和检查点；确认输出仍须满足原节点 schema/accept。停止等待实际退出，跨连接通过 SQLite 控制请求通知真实执行器。Pause/Stop 可绑定本轮 owner token，容忍进度 revision 更新；上一轮 token 不能控制新执行。

本版不承诺任意外部副作用恰好执行一次，不自动回滚项目，也不承诺全 App 只有一个插件 PID。安装、发布与当前聊天加载版本分别核对。未运行 REA 生产更新流程，未宣称它已验收。
