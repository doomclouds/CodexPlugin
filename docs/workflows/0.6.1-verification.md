# Workflows 0.6.1 验证记录

0.6.0 新增本地原地修改模式，详见 [功能与验证](0.6.0-verification.md)。收尾复查发现，普通非 Git 目录中的嵌套 Git 仓库可能只被当作文件树，导致其 Git 元数据未进入恢复检查点；Git 项目内的未注册嵌套仓库原本已经拒绝。

0.6.1 对非 Git 目录增加同样的明确拒绝，避免静默复用缺少 Git 语义的检查点。普通非 Git 项目、独立 Git 项目、linked worktree 和注册子模块的行为不变。新增回归同时验证首次创建和运行后的检查点检查，并确认原项目源码与嵌套仓库元数据未被修改。

类型、构建、发布结构和 140 项本地模块、删除、引擎、协议与面板定向检查通过。0.6.0 全仓检查及真实双 worker 修复验证继续保留，详见对应记录。

发布提交 `64b98f3` 已推送 GitHub main，并从 GitHub 市场安装 0.6.1。全部 129 个安装文件与发布源码逐字节一致，无缺失、差异和额外文件；签名桌面 CLI 加载器通过，21 工具与仅 thread 入口保持不变。

正式 MCP SDK 连接实际安装包的自包含运行入口，在一次性非 Git 项目中完成：保存本地模式定义、读取并核对模式、带来源新建预览、启动真实 gpt-6-luna / max worker、等待完成、从宿主独立运行测试、拒绝无需执行的应用、按预览指纹删除定义与关联运行。源码差异严格为预期的 `sum.mjs`，原有备注及测试文件不变；运行目录清理后原项目中的修复与测试结果保留。未使用测试适配器、未修改用户真实项目或配置。

当前聊天实际能力仍为 0.5.10，支持的模式仍只有 snapshot 与 git-worktree；需要重开 App 加载新版后才能在这个原生面板选择 local。安装包协议、真实 worker 和开发浏览器的结果不等于旧连接已热更新。
