## 宿主连接问题

REA 静态分析与宿主诊断日志确认，macOS 原生项目管道在处理帧前拒绝无受信签名的进程链，导致 EOF。协议帧本身匹配正式客户端。启动器使用官方动态运行时变量并原地替换进程，保持父进程链；没有修改宿主签名校验或绕过授权。

未知／过期租约会重新建立面板连接、读取真实状态；断线期间显示上次记录，暂停动画和计时。临时读取故障有界退避，页面重新可见或手动操作可再连接。恢复连接不自动启动／恢复任务。

外部 SDK 创建的临时 CLI 聊天未被当前 App 视为真实聊天，因此严格项目列表测试仍不能证明主窗口的项目归属；该测试保留失败断言。最终项目列表与当前聊天实际加载版本，须 App 重载新版后核对，不能用原生目录探针代替。
