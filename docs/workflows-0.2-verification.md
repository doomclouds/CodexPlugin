# Workflows 0.2.0 验证记录

日期：2026-10-13。本记录针对仓库源码与随插件分发的自包含运行包。当前 App 的旧安装包不随本地构建自动更新。

## 自动化检查

`npm run check` 覆盖 TypeScript、MCP 和面板构建、插件结构、协议冒烟以及运行时测试。协议冒烟从仓库外、没有 `node_modules` 的临时目录启动 MCP 运行包，并执行无 worker 的真实 QuickJS 脚本；执行结果不是模拟器返回值。

测试分别覆盖协议事件顺序与取消、JS 隔离和资源上限、并发调度、缓存失效和重放、多进程互斥、崩溃记录恢复、模板库版本与跨项目复用、快照与二进制差异、冲突与路径边界、面板生命周期和主题变量。协议测试中的服务进程以及运行时单元测试中的 worker 是明确的测试替身；它们不作为真实模型调用证据。

## 真实 Codex worker

使用本机 Codex CLI `0.162.1`、现有登录及默认模型，没有修改用户配置或读取凭据内容。

| 检查 | 结果 |
| --- | --- |
| 只读 worker | 读取固定临时文件，返回预期 JSON，源文件不变 |
| 写入 worker | 临时加法测试先失败，worker 修改实现后独立重跑通过 |
| 运行中断 | 实际收到 `turn/completed` 的 `interrupted`；app-server 和转发进程均退出 |
| 父进程硬退出 | 无模型的真实 `command/exec` 运行时强制终止控制进程；stdio EOF 后 app-server 和命令进程均退出 |
| 完整动态脚本 | QuickJS 传递 args、阶段、schema，调用真实写入 worker |
| 隔离与审查 | 执行完成后原项目未改；真实差异仅包含被修复文件；隔离区测试通过 |
| 持久化 | 关闭并重建运行时，保留完成状态、结果和输入，没有自动启动 worker |
| 明确应用 | 应用后原项目独立测试通过 |

完整流程调用 1 个真实 worker，没有重试。单独只读验证曾遇默认模型容量不足，同模型重试成功。全部临时项目、工作区和状态已清理。

父进程硬退出检查仅证明本机 `0.162.1` 的 stdio EOF 和一个活跃真实命令的清理行为；不扩展为所有 CLI 版本、模型 turn 或操作系统崩溃路径的保证。

可手工重现完整流程：

```sh
npm run smoke:real --workspace=@codex-plugin/workflows
```

该命令明确调用真实模型，使用可删除的临时 Git 项目，未纳入日常 `check`。
