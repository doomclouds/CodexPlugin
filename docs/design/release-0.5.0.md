# Design 0.5.0

本版把设计系统、多页面编辑和可编辑交付接到同一份真实源码，同时重做本地案例与艺术指导。发布沿用 GitHub `main` 市场源。

## 本版变化

- **真实多页面画布。** 同屏比较最多4个实际页面，各自选择尺寸、交互、定位源码并进入单页。修复画板信息和重载提示遮挡页面的问题。
- **CSS 源码令牌。** 从实际 CSS 声明读取颜色、间距等变量，按准确身份批量改值并保留其他源码；删除脱离 CSS 的旧令牌元数据。
- **可编辑组件库。** 保留真实 TSX/JS/CSS、传递源码、素材与许可，以独立命名空间追加；拒绝覆盖已有库及手工修改。
- **完整工程往返。** 导出源码、页面与路由、设计系统、评论和素材，重新打开 ZIP 创建独立可编辑副本，保留原工程。原有显式目录比较、冲突保护和恢复继续适用。
- **更清楚的操作与上下文。** 改善明暗主题、选中与键盘焦点、已解决评论、模态和历史操作；仅描述性元数据更新时保留原型输入状态。当前聊天需求保持完整，文件与评论按需窄读。
- **本地设计知识与十套重做案例。** 包内提供宽窄截图、自包含源码、素材、说明与许可。艺术指导从设计哲学、问题、方法和实现机制推导形式，明确视觉红线、合格表现和制作前验收约定；一次落地选择一个主方向，既有品牌优先。
- **真实图片与大文件交付。** 大结构化结果减少重复文本；导出不超过3MiB时返回内联字节，更大时保存同一不可变 artifact 并回显路径。取消下载不静默保存，快照不随后续工程修改改变。

十套案例分别为 `editorial-atlas`、`operations-console`、`typographic-event`、`interactive-product`、`museum-journey`、`quiet-hospitality`、`material-catalog`、`civic-wayfinding`、`audio-studio` 与 `independent-archive`。它们是可研究的原创示例，不能把数量、程序检查或作者评审当作用户验收或竞品超越证明。

## 格式与使用边界

当前工程格式为 `schemaVersion: 3`。旧开发格式不兼容，不自动迁移、删除或改写原文件。私有生成草稿仍为格式2，内部参考快照为格式3；旧参考快照也明确拒绝，不提供兼容分支。

默认使用当前聊天的模型与授权工具；独立 Codex 模式仅在用户选择后通过本机现有登录工作，不需要 API Key。安装或市场更新不等于当前聊天已经加载新版，应在重启后的聊天核对 `design_get_capabilities` 返回的版本和格式。

发布检查覆盖类型、构建、可移植性、真实源码与浏览器回归，以及脱离开发工程的运行包和全部案例资源。受控测试和当前聊天制作分别记录；没有用测试替身声称完成真实独立模型推理或所有宿主验证。

本版仍是开发预览版。未完成三方产品的同条件对标，不宣称已达到或超越 Claude Design。ChatGPT 原生宿主、独立模型与全部平台的完整矩阵尚未验证；原生宿主下载能力以实际宿主为准。单份大型结构化内容仍受客户端消息上限约束。

在线多人协作、云端分享，以及独立 Motion 时间线、视频渲染和 MP4 导出尚未实现。本版保留前端原型中的实际 CSS/JS 动效，不把它等同视频制作产品。

研究草稿、任务工程、验证截图、日志、导出文件和临时数据留在本地，不进入本版提交；插件所需的最终案例与运行包一同发布。
