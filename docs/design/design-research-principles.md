# Design 研发与灵感研究原则

更新日期：2026-10-17。目标：持续吸收同领域产品的长处，也跨领域寻找改进设计与使用体验的方法。**本文件规定研究方式，不表示下列灵感已采样、实现或验证。** 静态产品与 Motion 的阶段顺序仍以 [质量门槛](static-quality-gates.md) 为准。

## 1. 同域优势：先解释机制，再适配本地

对每个值得吸收的优势，完成一条完整记录：

**用户问题 → 对方如何解决 → 证据与边界 → 起作用的机制 → 本地适配 → 对照验证。**

1. 从具体任务出发，例如“连续改稿后无法确定改动范围”，不从“竞品有某按钮”直接进入复制。
2. 分清实际操作、源码/协议、公开说明和主观判断；固定版本与源路径，缺少账号或运行证据就标未知。
3. 提炼机制，例如稳定对象身份、渐进披露、同一源码预览与导出，而非只抄控件形状或宣传措辞。
4. 对照本地 Codex、现有登录、MCP App、项目文件及自包含发布边界设计实现。外部云端服务和宿主权限不能默认移植。
5. 在相同 brief、输入和修改任务中比较原方案与适配方案；只有解决了原问题，才进入保留队列。改动破坏其他任务时记录代价。

同域研究既找优点，也找其失效条件和我们的反例。源码存在、案例数量与品牌知名度均不能替代效果证据。

## 2. 跨域发散：把灵感变成可检验假设

以下是待探索的方向，不是指定产品风格。每次只挑与当前 brief 有因果关系的少量假设。

| 来源领域 | 可迁移的问题与假设 | 适用 / 避免条件 | 可以怎样比较 |
|---|---|---|---|
| 出版与编辑 | 用标题角色、段落节奏、旁注和图文关系建立阅读入口，而非把内容平均拆成卡片 | 适合知识、报告、文化内容；密集操作区避免套用巨型标题和长卷节奏 | 找到指定信息的步骤/时间、中文阅读顺序、同内容层级对照 |
| 建筑与空间 | 用分区、通道、边界和留白表达对象关系与下一步，让人知道“我在哪、往哪走” | 适合多区工作台、导航与渐进流程；避免为了空间比喻牺牲真实任务效率 | 路径选择、迷失/返回次数、主要操作是否被遮挡 |
| 工业设计 | 从可操作性、手感、阻尼与反馈推导控件层级和操作回执 | 适合编辑器、高频工具、触控控制；避免只有拟物外观而没有动作反馈 | 按压/焦点/禁用/错误状态辨识，误操作与恢复成本 |
| 数据叙事 | 先决定需要解释的比较、变化或关系，再选择编码与证据顺序 | 适合分析、报告和仪表盘；避免假曲线、装饰 KPI、用图形掩盖缺数据 | 是否读出正确结论、单位/范围是否清楚、相同数据的替代表达 |
| 影视与视觉叙事 | 用焦点、尺度、景别和信息揭示顺序形成清楚的静态阅读节奏 | 适合品牌叙事与发布内容；当前阶段只研究静态构图/状态序列，不能借此提前启动 Motion | 首眼信息与后续阅读是否符合任务，是否出现无关戏剧化处理 |
| 导视与地图 | 用稳定编码、地标、当前位置和返回路径帮助用户建立心智地图 | 适合多页面原型、复杂工具和文档；避免无解释的抽象符号 | 定位与返回任务、编码一致性、颜色之外是否仍能理解 |

跨域不是把多个知名流派拼在同一页。应提炼可解释的关系：哪一种构图、空间、反馈或节奏改变，预计改善哪一个用户问题；没有这条关系就暂不采纳。

## 3. 一次探索的最小闭环

1. **绑定 brief。** 记录受众、主任务、内容/素材、品牌、平台、保留区域与已有失败。
2. **提出假设。** 写清来源、机制、预计改善、适用条件、避免条件，以及可能牺牲什么。先做真正不同的概念，而非同一版式换颜色。
3. **保留对照。** 使用相同内容和约束，比较原方案与少量候选；需要实际素材时先核实可取得及使用范围，不能用尚未取得的图片作为完成证据。
4. **查看与操作。** 按任务看真实画面、检查中文和响应式、操作主路径，记录修改与交付成本。还没运行就保持“待验证”。
5. **决定保留、修改或拒绝。** 关联证据和反例；失败方案保留其假设、条件与失败原因，不删掉来美化成功率。
6. **回写产品知识。** 仅把反复有效的机制变成按需规则或组件。规则携带适用/避免条件，不能变成所有任务的默认皮肤。

与既有品牌冲突时先保留用户明确要求；如果认为另一个方案能解决问题，应提出带证据的替代供比较，不能借灵感研究擅自重做无关区域。

## 4. 决策记录

每条候选按以下字段记录，研发、实现和评审共用同一身份：

```text
记录 ID / 状态：待研究、待采样、待验证、保留、修改、拒绝
brief / 用户问题 / 当前基线：
同域来源或跨域参照 / 版本、路径、许可与证据等级：
机制与假设 / 适用条件 / 避免条件 / 预期代价：
候选与对照 / 预定评价方法：
实际样本、运行包、项目修订、画面和操作结果：
反例、失败、剩余未知：
决定与理由 / 后续回归条件：
```

当前尚未登记新的跨域采样成果。后续结论必须限定在已测试任务与条件内；引用优秀作品不等于复制其资产获授权，借鉴方法也不等于已经改善自己的产品。
