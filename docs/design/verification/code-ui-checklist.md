# 真实源码编辑器操作验收清单

日期：2026-10-17。此文件是验收方法；通过范围以具体记录为准。当前只保留真实 HTML/React/TSX/CSS 项目，不包含已淘汰的图层编辑器测试或旧格式迁移。

## 入口与证据

1. 记录 `design_get_capabilities` 的版本、源码项目 ID/revision、运行包 hash 和宿主。
2. Codex 原生 MCP App 与开发预览分别登记。localhost 仅作开发验收，不能替代原生宿主；截图、协议、真实操作和模型推理也分别登记。
3. 使用专用验收项目，不覆盖用户未保存草稿。每批操作后读当前 DOM/AX，再使用实际显示的控件；页签、评论数和按钮状态会动态变化。
4. 预览尺寸以真实 iframe 宽高为准。画布缩放不改变运行视口；多尺寸的顺序不能硬编码。无法点击嵌入帧或截图时明确限制，不模拟宿主事件。

常用外层控件：

| 对象 | 当前语义定位 |
| --- | --- |
| 项目、页面、尺寸 | combobox：`当前原型项目`、`当前页面`、`预览尺寸` |
| 源文件 | button：`打开 src/App.tsx`（按实际路径） |
| 源码 | textbox：`src/App.tsx 源码`；button：`保存源码` |

| 评论 | button 名称随未解决数量变化，例如 `评论 · 1`；状态操作为 `标记已解决` / `重新打开` |
| 导出 | button：`导出代码原型` |

## 源码、定位与评论

- 保存一项窄范围文字修改，实际回读目标文件 hash 与 revision；其余源文件不变。保存结束后撤销/重做按钮必须恢复可用。
- 撤销后跨过保存/轮询再回读，不能有旧输入晚到的 update；重做恢复同一项修改，真实 history 与源码一致。
- 对当前编译器确认的静态 literal 使用元素工具或 Inspector 改文案；动态表达式、运行时文字和祖先映射不能被当成静态文字覆盖。
- 为语义对象添加评论，记录 comment ID、sourceId 和文件 hash。在源码前增加无关行后重新编译，评论仍定位同一 sourceId 的新位置。移除标记后明确失锚，不能按旧 offset 猜绑。
- 点击评论定位后，Inspector 对静态/动态内容的判断应与直接选择一致；仅定位成功不能替代可编辑性检查。
- 在原生面板标记评论已解决，再重新打开，等待真正保存并通过工具回读状态。

## 冲突与状态

- 提交旧 revision 或旧文件 hash：必须拒绝，源码和历史不改变；不能换新身份原样重发旧全文。
- 保留未保存 textarea 草稿，另从 MCP 改同一文件：面板保留草稿并说明冲突，不能自动覆盖服务器或用户输入。
- 有脏草稿切项目时不得静默丢失；无脏草稿切到 B，A 的晚到 hydrate/保存结果不能替换 B 视图或 hash。
- 在原型中输入/筛选/展开，再切非编辑面板、选择/交互模式和同修订轮询，临时状态不应被重建。源码重编译、导航和刷新后的状态策略单独说明。

## 真实交互与响应式

- 使用固定数据核对搜索、筛选、排序、选中详情、空结果与恢复动作。无结果保留查询/条件；错误不伪装成空列表。
- 受控重试真实改变行、详情、计数和按钮，提交中防重复；明确本地模拟范围，不声称操作真实服务。
- 1440、768、390px 实际查看中文长标题、状态、选中/禁用/焦点；窄屏完成同一主任务，不能只给桌面缩略图。
- 键盘操作覆盖主行动、关闭详情/导航和恢复路径；记录焦点、滚动和水平溢出问题。
- 页间导航指向真实 pages/route；query/hash 在入口脚本首次执行前可用，普通链接与页面绑定尺寸不会误选。

## 源码目录往返

- 新导入的真实目录首次写回不被误判为无关文件。导入只读，连接位置/基线为私有数据，不进入导出工程。
- 外部单端改动可以显式拉回同一项目；不重建项目、评论或页面身份。项目单端改动只写用户选中的文件。
- 同文件双端改动展示实际两端及 hash；外部再次保存后拒绝旧选择，保留新内容。
- 制造第二文件写入失败：返回真实已写和待处理项；重开后显式重查现场，不自动继续或声称回滚。
- 受管符号链接、不可读文件、BOM、未受管文件与目录身份替换分别检查。展示摘要截断不能影响安全判断。
- 连接目录的 journal 与其它目录的普通 manifest 导出区分；没有恢复实现的路径不宣称可恢复。

## 导出与模型边界

- 源码 ZIP 包含实际 HTML/TSX/CSS/素材与当前 revision；检查包内路径，在隔离目录运行 prototype 并操作主任务，再导入源码继续编辑。
- PNG/PDF 来自真实浏览器，核对媒体头、尺寸、hash 与画面。没有下载能力时使用真实 `design_code_save_export` 路径，不把尝试下载写成已保存。
- 默认当前聊天。独立模式只有用户选择才启动，目录来自本机真实 Codex 返回；列出模型不等于完成推理。
- 编译、渲染、模型看图、交互、提案完成与应用分别登记。未验证消息进入同一聊天时，保留该缺口；不靠构造宿主事件声称通过。
