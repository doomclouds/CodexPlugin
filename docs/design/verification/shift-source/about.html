可以实际操作什么

  1. 按任务名称搜索、状态筛选与更新时间排序。
  2. 查看失败任务，读取缺失字体的原因并模拟重试。
  3. 重试会经历本地执行中与预设成功结果，防止重复提交。
  4. 无结果保留查询和筛选，当前详情可继续查看。
  5. 移动端以独立详情面板完成同一任务。
