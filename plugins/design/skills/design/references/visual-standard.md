# 视觉红线与合格表现

用于艺术指导、新视觉与精修。以世界一流设计师与艺术总监的标准形成作品；下面是设计判断，不是自动认证或客观分数。先判断视觉观念是否成立，再看执行。排印细节见 [排印工艺](typography.md)，操作与焦点见 [表单与状态](forms-states.md)。

## 先形成可见的设计观念

用一句话确定：给谁、表达什么、主要视觉关系是什么、为何只有这个内容适合这样表达。选定一个主方向，把色彩、字形、图像、尺度和交互组织成同一语言。参考只借有用机制，不拼接几套全局视觉。

明确一处值得记住的视觉决定，例如以断裂的字面表现声音间隙，以建筑光线安排旅宿页面的阅读节奏，以刊物跨页组织论证。它必须进入实际比例与内容，不能只写在标题或设计说明里。若换一个产品名仍能原样使用，继续推敲立意。

## 参考研究必须走到方法与实现

| 层次 | 必须回答的问题 | 需要留下的可复用结果 |
| --- | --- | --- |
| 哲学 | 参考如何理解内容、受众、秩序、情绪或材料？ | 一项有依据的设计立场；作者原意与从画面推断分开 |
| 问题 | 它在什么约束下解决了什么问题？ | 受众、内容、载体和限制，避免脱离语境模仿 |
| 方法论 | 它怎样选择、抽象、删减、排序或制造对比？ | 可用于新内容的决策过程，不能只列风格名 |
| 形式规则 | 上述决定如何变成比例、网格、字形、色彩、裁切与节奏？ | 清楚的主次、角色与关系，解释为何这样安排 |
| 实现机制 | 如何做出相似的观看或操作效果？ | 实际素材、布局结构、字体加载、渲染/动态方法、断点和状态的具体路径 |
| 验证与边界 | 换成当前内容后效果是否仍成立？哪些不能搬？ | 同内容局部实作与真实画面，记录有效机制、失败条件及舍弃项 |

先看实际作品，再核对可得的设计说明、原始源码或一手资料。没有依据的哲学解释标为推断；大师或工作室名称不能代替分析。研究结果须成为本地可执行知识；不得要求执行时去外站寻找缺失规则、素材或代码。

## 制作前固定可验收的设计约定

每个作品用简短表格写清以下内容，再制作主画面：

| 约定 | 验收方法 | 证据 |
| --- | --- | --- |
| 核心观念及一个主要视觉决定 | 在实际截图标出它如何由内容进入形式，并作换题材检验 | 主画面与具体说明；属于视觉判断，不自动打分 |
| 首屏主次与阅读顺序 | 写明先看、再看和主要行动；在实际宽窄画面对照 | 对应尺寸截图及指出的具体元素 |
| 字体、字号角色、色彩与素材 | 固定本例的具体值/资源，检查真实加载、计算样式、裁切与对比 | 源码、资源、浏览器读回；普通文本对比至少4.5:1，大字至少3:1 |
| 窄屏构图与边界 | 写明重排顺序、保留的主体/动作，检查无整页横溢出和控件遮挡 | 实际窄屏截图、尺寸与边界读回 |
| 关键操作及恢复 | 预先列出触发、预期状态、焦点与保留内容，真实执行 | 操作后的状态和焦点读回 |
| 最终视觉与设定一致 | 逐项指出合格表现；命中红线即不通过，有争议保留待审 | 实际画面、独立评审与明确的保留/淘汰理由 |

大字指至少24 CSS px的常规字，或至少约18.7 CSS px的粗体字。图片背景上的文字须核对实际承载区域，必要时改变字面位置、底面或色彩。键盘焦点与主要操作应完整露出，不被自制固定控件遮挡。

表格中的事实检查与视觉判断分开。事实检查通过不能代替观念、构图和素材品质；视觉理由也不能豁免可读性与真实行为。记录真实文件/页面身份、尺寸、已执行操作与未覆盖项，不以截图存在或作者自评宣布通过。不通过时回到对应设计决定修正；若受预算或能力限制，保持未完成，不能降低标准。

## 红线：出现即退回视觉设计

| 红线 | 实际可观察的问题 | 处理 |
| --- | --- | --- |
| 没有内容身份 | 通用标语、大标题、三卡片、指标和按钮换名后可用于任何项目 | 从具体题材重新提出构图与母题，不能只改色板 |
| 把实现结构当作品 | 算法节点、表单、参数、调试状态直接堆在首屏，视觉主要在解释程序怎么工作 | 先建立内容世界与观看顺序，再把机制融入恰当层级 |
| 素材达不到表达要求 | 简陋形体、低精度插图、假摄影或装饰波形承担主视觉，却无法支撑题材质感 | 制作或取得足够好的原创、获许可或明确标识的概念素材；不可把缺素材当作降低标准的理由 |
| 构图没有主次 | 标语、色带、图像、结果、控制条同时争抢，或大片留白没有节奏与目的 | 调整视觉重量、尺度、裁切与停顿，先让一个主体成立 |
| 装饰代替设计 | 英文小标签、圆角框、细线、霓虹色或渐变承担全部“设计感” | 逐一说明其作用，删去无内容依据的包装，保留真正有表达力的部分 |
| 细节或窄屏失控 | 中文语义断裂、弱对比、对齐松散、焦点被遮、手机仅把桌面模块顺排 | 在实际尺寸重构图并精修，连同关键状态一起回看 |
| 验收偷换 | 用能运行、无错误、截图已生成、案例数量或主观自评分宣布视觉优秀 | 分开报告工程事实与视觉判断，指出仍不成立的画面与原因 |

特定颜色、衬线、SVG、卡片或留白本身不构成红线；判断依据是它在这个作品里的质量、作用和整体关系。用户明确否定的方案回到设计阶段，不因已有实现成本继续沿用。

## 合格表现：必须从实际画面指出证据

- **立意可见。** 构图、图像或文字处理承担题材表达，能指出一项不可随意替换的设计决定。
- **整体有辨识度。** 缩到缩略图仍有清楚轮廓与视觉重心，恢复实际尺寸后信息与主要动作同样清楚。
- **排印经过设计。** 展示、阅读、数字与操作各有角色；中文换行、行长、字重、节奏和留白能支撑内容温度。
- **素材值得成为主体。** 主视觉在结构、光线、质感、裁切与细节上经得起看；来源和概念身份准确，说明不过度占据主要体验。
- **空间有节奏。** 强弱、密实与安静区域有意安排；每个断点都重新建立观看顺序，避免所有题材共享一个网页骨架。
- **交互属于设计。** 选择、阅读、比较或试听强化同一个观念；正常、空、错误、焦点和恢复状态仍保持完整语言。

合格表现不能抵消红线。不写没有依据的“90分”“顶级认证”或“超越竞品”；以看过的具体画面与执行过的操作说明判断。

## 素材与审美工作法

按题材选择媒介。摄影型内容需要有质量的摄影或明确标识的概念视觉；精确关系用矢量与代码；排版可以独立成为主视觉。使用宿主可用的生成图像能力时，把实际资产放进项目或发布包，确认裁切、字节和真实加载，不只在提示词里描述一张不存在的好图。

先做一张足以证明方向的真实主画面，并放到实际宽窄尺寸看。方向没有成立就重构，方向成立后才扩展状态与页面。评审要写出“保留什么、淘汰什么、为什么、改后的画面如何证明”，不能用泛泛赞美替代判断。视觉证据不足时保持待审，不为了完成清单给自己放行。
