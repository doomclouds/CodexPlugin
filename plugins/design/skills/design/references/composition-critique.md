# 构图、密度与有依据的精修

用于新页面、实质不同的方案与已有设计的视觉修正。先从真实任务形成空间关系；字体细节见 [排印工艺](typography.md)，有操作的区域补读 [表单与状态](forms-states.md)。

## 用内容建立一个主关系

1. 记录受众要完成的一件事、主要对象、关键证据、下一步行动和必须保留的内容。信息足够时直接作合理假设，不为选风格强迫问卷。
2. 盘点真实可用的文案、数据、图像、组件和约束。没有摄影时选择能靠排版或示意成立的表达，不能靠假照片与假评价填满首屏。
3. 选择一个内容关系作构图核心：对象与详情、论点与证据、输入与结果、作品与索引、步骤与变化。先安排其余信息如何支撑它，再决定容器、色彩和装饰。
4. 让一个能被复述的主体细节进入主要视觉，例如材料的连接方式、报告中的真实变化或工具的关键操作。暂时遮住品牌名后，内容仍应能说明这个项目在做什么。

| 主任务 | 空间优先级 | 不应牺牲的内容 |
| --- | --- | --- |
| 高频工作台 | 对象可扫描，当前选择和高频行动相邻 | 身份、状态、单位、异常与恢复路径 |
| 连续阅读 | 正文主线稳定，目录与旁注提供定位 | 完整论证、条件、出处与图注 |
| 品牌或作品 | 一个有内容依据的主视觉与清楚行动 | 真实作品、规格、参加方式或下一步 |
| 对比决定 | 候选共享维度、尺度和来源 | 条件、代价、缺失值与不确定性 |
| 机制解释 | 变化顺序、边界与因果清楚 | 箭头语义、发生条件与文字等价说明 |

密度由需要同时比较多少对象、每个对象需要读哪些字段决定。先处理重复边框、无用标签、过大标题和错误分组，再考虑缩小字号。少量记录不必制造趋势图；卡片数量与等高排列也不构成信息架构。

## 从其他领域借机制

发现可用参考时，说清“借哪种关系、解决什么问题、在哪些条件下失效”。例如用出版的主文与旁注处理知识层级，用导视的当前位置和返回路径处理详情导航，用工业面板的目标与回执处理操作确认。把这些关系写入自己的内容与源码，再验证用户是否能完成任务；不把材质、配色或一个形状直接当作功能改进。

没有看过实际参考作品时，将类比作为设计假设，不声称已经完成跨域作品研究。用户提供具体参考后，保留其内容顺序、比例与交互意图中真正相关的部分，避免无关品牌和未经确认的资产进入交付。

## 响应式要重排关系

下面是对象列表加详情的一个起点。布局子项允许收缩；窄屏把详情移到列表后。若任务要求独立详情面板，需要补上真实打开、返回、焦点与保留选择的行为，不能只隐藏重要内容。

```css
.workspace-grid {
  display: grid;
  grid-template-columns: minmax(0, 1fr) minmax(16rem, 22rem);
  gap: 1.5rem;
  align-items: start;
}
.workspace-grid > * { min-inline-size: 0; }
.object-name { overflow-wrap: anywhere; }
.object-number { white-space: nowrap; font-variant-numeric: tabular-nums; }
@media (max-width: 52rem) {
  .workspace-grid { grid-template-columns: minmax(0, 1fr); }
}
```

在实际数据下决定何时折叠，不把断点当作固定设备分类。窄屏保留身份、状态与主要行动；表格保留行列对应关系，复杂比较可使用有边界的局部滚动。不要靠整页缩放或统一 `overflow: hidden` 消除问题。

## 方案比较与精修

需要探索时，对同一内容和约束改变入口与阅读顺序、信息密度或主关系。比如列表先行与异常先行、连续阅读与问题索引、说明先行与演示先行。每个候选都保留必要内容和真实操作；只换颜色、字体名或背景不算实质差异。没有比较交付要求时，自行选合适候选继续，不为展示流程停在选择题。

精修先看当前真实画面和目标状态，再按影响选择少数问题。用“看到什么 → 影响谁的哪一步 → 对应源码 → 改哪一处 → 如何复查”记录；例如长名称把恢复按钮挤出屏幕，就检查该行布局与窄屏操作，而不是重做全站配色。

优先处理读不清、点不到、内容缺失和身份混淆，再处理间距与视觉节奏。一次修正后重看受影响的实际尺寸、主题与操作；沿用已经通过且未受影响的证据。快改只核对相关区域，标准和精修通常最多两轮集中检查；用户指定的范围与投入优先。仍有问题就说明影响和保留项，不制造未经测量的质量分数或“超过竞品”的结论。
