# 排印工艺

用于中文、混排、长文、数据与长标题。先确认内容和阅读任务，再调整字体与比例；已有品牌和局改范围优先。字体来源、源码修改和交付方式遵循 [代码项目参考](code-project.md)。

## 从内容建立角色

1. 取本次真实最长标题、正常正文、长路径、数字与中文英文混排各一份。使用真实句子，不用短占位词替代边界。
2. 读取现有 CSS 变量、字体声明与组件样式，区分正文、展示、操作、数据和代码。先复用可用角色，缺少角色时才新增。
3. 根据主任务决定空间：工作台标题让出操作面积；阅读页控制正文行长；品牌页允许一个展示关系成为焦点；数字需要单位和比较基准。
4. 在真实宽窄视口看换行，再改字号、行高、容器宽度或措辞。一次只调整能解释问题的变量，保留已确认的内容和品牌。

| 内容角色 | 要建立的关系 | 避免 |
| --- | --- | --- |
| 连续中文正文 | 行长、回行距离、段落间隔适合持续阅读 | 为容纳宽表缩小整篇字号；拉满大屏 |
| 中文标题 | 词组完整、主次明确，换行后仍留出导语和行动 | 从拉丁展示字继承紧行高、负字距；靠旧文案的固定断行 |
| 高频操作 | 标签、值、帮助和错误各有角色，状态后仍可扫描 | 全部小灰字；每个分组都用展示大标题 |
| 数字与时间 | 同列对齐、单位邻近、精度一致 | 没有依据的小数；所有数字都放大争夺注意 |
| 路径与代码 | 原文可完整读取，局部滚动或合适换行 | 全页横移；省略关键路径且没有展开方式 |

## 中文与拉丁文字分开控制

下面是阅读页的起点，使用系统回退即可运行；保留项目已有合格字体时不必替换。数值需要用实际字形和内容调整。

```css
.reading-copy {
  font-family: system-ui, sans-serif;
  font-size: 1.0625rem;
  line-height: 1.8;
  letter-spacing: normal;
  max-inline-size: 34em;
}
.reading-title {
  font-size: clamp(1.75rem, 4vw, 2.75rem);
  line-height: 1.35;
  letter-spacing: 0;
  text-wrap: balance;
}
.reading-title .latin-display { letter-spacing: -0.025em; }
.numeric-value { font-variant-numeric: tabular-nums; }
.source-path { overflow-wrap: anywhere; }
.code-scroll { max-inline-size: 100%; overflow: auto; }
```

只有确实是拉丁展示文字的子元素才使用 `latin-display`，不要套在含中文的共同父元素上。`text-wrap: balance` 只帮助长度平衡，不能保证语义换行；检查中文标点、孤字、长产品名和混排。正文中的英文术语不因此必须使用另一字体。

滚动代码块在需要键盘进入时给实际滚动容器 `tabindex="0"` 和可理解的名称；靠近宽表提供可横向阅读的提示。不要给所有普通正文加横向滚动。检查标题锚点的 `scroll-margin-block-start`，固定导航不能盖住跳转目标。

## 字体必须实际存在

先核对项目中的文件、引用路径和适用许可。默认离线预览使用项目资产或可用系统字体；缺少字体时明确使用回退，不把未加载的品牌字体写成已实现。

在真实浏览器等待字体加载状态，查看关键中文与拉丁字形及其宽度、截断和换行。`font-family` 的 computed value 只表明声明链；`document.fonts.check()` 或一次加载完成也不能证明每个中文字符都由目标字体提供。需要精确品牌字体时，结合可用的实际字体检查能力及画面判断；没有这种证据就说明回退边界。

## 只报告看过的范围

在本次必要尺寸下，读完标题、连续正文和长边界文本，检查缩放、字体回退及字号变化后的按钮和表单。局部修改重看受影响行与邻近操作；导出 HTML 或工程时，打开实际交付物再核对字体和同一长文本。记录源修订与剩余问题，不把 CSS 声明或生成截图当作排印验收。
