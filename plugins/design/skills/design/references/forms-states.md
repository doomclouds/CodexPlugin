# 表单、状态与控件清晰度

用于输入、筛选、保存、工作台操作和明暗主题控件。先确认操作能改变什么、由谁确认结果，以及失败后如何继续；前端本地状态与真实服务分别说明。需要空间取舍时补读 [构图与评审](composition-critique.md)。

## 把状态绑定到真实对象

先列出此次实际存在的状态和触发条件，再实现控件。静态文章不必添加不存在的远端加载；有服务的提交也不能用固定计时器伪装结果。

| 状态 | 页面应提供 | 需要读回的事实 |
| --- | --- | --- |
| 初始或未触碰 | 清楚标签、必要格式和主要操作 | 尚未编辑时不满屏显示错误 |
| 编辑或已离焦 | 保留输入，按合适时机提供帮助或校验 | 返回上一项、重开面板时内容仍在 |
| 输入无效 | 说明具体字段与如何修正，保持其他字段 | 错误与字段关联；修正后相应提示更新 |
| 提交中 | 说明目标与正在做什么，防止重复执行 | 一次意图只触发一次实际提交 |
| 完成 | 对象、详情或保存身份反映真实结果 | 不只靠一条成功通知 |
| 服务错误或结果未知 | 保留输入与目标，说明已知范围和下一步 | 未确认结果前不自动重发有副作用的动作 |
| 空或无结果 | 区分尚无对象与筛选无匹配，保留条件 | 清除筛选或创建对象后可恢复 |

背景预检只能辅助输入，最终提交仍以权威结果为准。迟到响应需绑定对象与请求身份，不能把另一条记录的错误放进当前表单。取消等待与撤销服务端改动是不同能力，按实际实现表述。

## 输入与键盘

标签与输入建立真实关联，帮助和错误通过对应描述关联；确认无效后才设置 `aria-invalid`。多字段提交失败时提供可定位的错误说明，把焦点移到错误摘要或最需要修正的字段。不要每敲一个字就打断阅读或抢焦点。

模态对话框打开后焦点进入、正反 Tab 留在可操作区域、关闭后回到入口；背景不可操作。长列表可滚动，关闭与确认仍可到达。按钮保存时变为不可用会丢焦点的场景，先把焦点放在明确的状态或操作组，结束后按原意图恢复；用户已经转向其他控件时不抢回。

固定底栏、播放控制或悬浮工具条须为内容与键盘焦点留出实际空间。按当前控件高度设置滚动容器的 `scroll-padding-block-end`，必要时为目标设置 `scroll-margin-block-end`；在控件换行或尺寸变化后重新核对。用真实 Tab / Shift+Tab 走到末项，确认焦点文字、轮廓与主要动作完整露在控制条上方。

## 主题、选中与焦点分别可读

不要只检查静止的按钮背景。文字、图标、边界、hover、focus、selected、pressed、disabled 和原生下拉选项要逐项检查。焦点不借用选中颜色作为唯一表达，图标按钮有可理解的名称。

下面只演示两个主题中的局部语义角色，不替代已有设计系统，也不证明已通过对比或可访问性验收：

```css
.form-surface {
  --field-bg: #fff;
  --field-fg: #202824;
  --field-edge: #69766e;
  --field-focus: #185c42;
  color-scheme: light;
}
[data-theme="dark"] .form-surface {
  --field-bg: #202a25;
  --field-fg: #f0f5f1;
  --field-edge: #a0b0a6;
  --field-focus: #a2e2bb;
  color-scheme: dark;
}
.form-surface :is(input, select, textarea, button) {
  color: var(--field-fg);
  background: var(--field-bg);
  border: 1px solid var(--field-edge);
  font: inherit;
}
.form-surface option {
  color: var(--field-fg);
  background: var(--field-bg);
}
.form-surface :focus-visible {
  outline: 2px solid var(--field-focus);
  outline-offset: 3px;
}
.form-surface [aria-invalid="true"] { border-style: dashed; }
```

错误还需要文字，虚线不是完整错误表达。原生菜单的实际外观由浏览器和系统共同决定；声明 `option` 样式并不保证所有宿主都采用，必须实际展开核对。禁用状态保持名称可读，并让用户理解不可用原因；不要给整个面板降透明度，连正文一起变灰。

## 按真实路径检查

使用实际长内容，执行输入、离焦、无效提交、修正、一次提交、失败与恢复。切明暗主题后用键盘聚焦并展开下拉菜单，检查文字、边界与返回焦点；需要窄屏时重复主要动作。同时核对对象行、详情与操作状态，记录已经执行的范围。只有本地示例时，让示例结果真实改变状态，并保留示例身份。
