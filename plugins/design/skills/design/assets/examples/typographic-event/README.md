# 间隙 · 活字与时间

[完整页面](index.html) · [桌面首视口](desktop.png) · [手机首视口](mobile.png) · [许可](LICENSE)

原创虚构设计交流日：2027年10月24—25日，两天各四场议程。人名、场地与活动均为示例；报名只做本地校验，不发送或保存个人信息，没有真实票务。

## 哲学：让“间隙”成为字面里的空间

交流发生在不同看法之间。这里把“间隙”两字的上下字面分开并轻微错位，让真正的留白承载“把边界留给想象。”；时间、地点与参与入口沿同一条版面展开。它借的是印刷海报中空隙与活字的关系，不是把标题放大、再旁置一张日期卡。

这个形式从活动名与交流主题推导，不是某位设计师的官方作品或认证。若换题后字面切分没有内容依据，应重新提出母题，而不是继续剪裂所有标题。

## 要解决的问题

活动页需要同时建立记忆点与可参与的信息：是什么、何时、哪里、如何了解议程。主视觉可以强烈，日期和操作仍必须清楚；双日日程与报名状态要属于同一语言。普通信息、操作和元数据不小于12px，不为一屏塞满内容压缩阅读字号。

适合设计活动、文化交流、文字主题发布。不要套到密集工作台、法规说明、医疗操作或长商品比较；正文和关键操作不采用装饰断字。

## 形式规则

- 整版朱红与墨黑建立视觉重量，纸白空隙真正切开字面；留白既是主题，也是完整主张的阅读底面。
- 展示字只在视觉层分片，语义H1完整；上下错位克制，活动名仍可辨，不依赖动效才能成立。
- 日期、年份、地点与主行动在同一条`time-band`，日程继续沿时间列展开，避免重复卡片。
- 手机重新安排字面尺度、空隙与日期行，保留可读主张、地点、报名和两日切换；删除过小重复英文，保留的信息按正常字号阅读。
- 朱红是这个虚构活动的表达选择，不是所有文化项目的默认色。已有品牌优先。

## 素材与代码机制

全部HTML/CSS/JS在[index.html](index.html)，没有图片、远端字体、CDN或第三方运行库。系统中文黑体承担字面，等宽用于日期与时刻。不同环境字形会变化，不能假定任意系统都保持完全相同的字面轮廓。

| 定位 | 实现关系 | 换内容时的动作 |
| --- | --- | --- |
| `.poster-letters`、`.glyph-upper`、`.glyph-lower` | 两份同字分别裁切上下半部，以CSS变量定义实际间隙 | 先看新字可辨性与主题关系，不机械沿用切口 |
| `.gap-band`、`#hero-title` | 实色留白承载完整标题，装饰字标记为`aria-hidden` | 保留完整语义、足够对比和自然换行 |
| `.time-band`、`.event-date` | 日期与参与信息成为海报的组成部分 | 年、月、日、地点与表单选项一起核对 |
| `.session`、`selectDay()` | 一份数据驱动日程、选中日期与面板关系 | 更换时间、议题、人物时保持同一数据源 |
| `dialog`、`.field`、`.feedback` | 原生弹窗、本地校验、错误与反馈焦点 | 接真实服务需独立实现接口和失败状态，不能只换成功文案 |

日期可点击，也支持左右键及Home/End；日程与选中焦点同步。报名会定位首个无效字段，错误保留已填内容。有效反馈明确说明未产生真实报名。关闭重开会清空输入，Escape使用原生关闭行为；减少动态偏好关闭平滑滚动。

## 如何验证自己的改稿

先在1440×1000和390×844看主画面：活动名是否仍可辨，留白是否承担主题，日期和操作是否清楚，有没有把普通信息缩成装饰小字。再看完整日程与报名状态，不能只核对海报截图。

实际切换两天并比对每场时间、题目、人物；用键盘验证选中和面板对应。提交空值、无效邮箱和有效示例，核对错误焦点、输入保留、明确的本地反馈与重开清空。日期来自虚构设定，不是现实活动通知；本例保留2027.10.24—25，不附不一致的星期或“周末”标签。

## 取舍边界

可借内容字面化、间隙与主张的关系、时间信息对齐和诚实表单状态。不要照搬“间隙”品牌、文案、朱红、日期或虚构人物。若新标题较长或字形弱，先重构海报和语义断行，不靠持续缩小解决。两张PNG仅代表初始首视口，不能替代全部状态、字体与平台的验收。
