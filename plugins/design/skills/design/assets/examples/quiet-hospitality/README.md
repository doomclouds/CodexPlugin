# 汀间：让建筑光线成为阅读节奏

[打开页面](index.html) · [宽屏主画面](desktop.png) · [窄屏主画面](mobile.png) · [许可](LICENSE)

汀间是原创旅宿概念。完整离线目录包括 `index.html` 与 `media/afternoon-room.png`；请保留相对目录一起使用。图片由内置图像生成能力制作，描绘虚构空间，不是纪实摄影、实际房源或服务承诺。代码、文案与本例概念素材按本目录 MIT 许可提供；字体使用声明的系统回退。

## 哲学与要解决的问题

本例的设计立场是：旅宿首先让人感知时间，而不是先让人处理一张表单。建筑中的开口决定光如何进入，日光又让灰泥、木、亚麻与树影显出一日的变化。这是本例作者的设计解释，不是引用具名设计师或酒店的宣言。

要解决的是“如何把安静做得可感知”：只有留白、绿色和慢生活标语，空间仍然可以替换成任何项目。因此让日光跨过墙面的方向成为主视觉，文字进入实际的墙面关系；选择日期之后，同一段时间才被具体化为夜数、起止与估算。

## 从立场到形式

宽屏先看房间的光，再读“日光经过，我们停留”，最后看到安排停留的行动。主图占据主要画面，展示字使用宋体角色；木色、亚麻与叶色来自概念图，纸面 `#f8f7f2` 与墨绿 `#23352d` 承担页面阅读。

图上的大标题使用更深的 `#08180f`，避免把墨绿在阴影中的可读性当作理所当然。小号空间与时间说明放在照片外的纸面，保留图像；照片不承担反复的工程声明。

手机重新构图：标题在纸面上，随后进入房间，裁切保留窗、树与榻。没有把所有桌面文字压进狭窄照片。展示字宽屏 92px、手机45px，正文14px，功能标签与图注至少12px；实际字形由系统可用字体决定。

## 怎样做出类似的空间与光感

图像不是靠 CSS 房屋剪影代替的。制作时先确定空间、材质、光线方向与可用裁切，再生成原始概念视觉。可借用的提示词关系是：

> 原创虚构旅宿的建筑编辑摄影；灰泥墙、深色木窗框、橄榄色亚麻榻；午后低角度日光在墙面与地面形成明确光影；真实微纹理与接触关系；左侧保留墙面阅读空间，右侧保留院子与座位；无人物、文字、标志或网页元素。

这是素材制作的方法，不保证换个题材仍成立。不要将同一房间图机械用作所有旅宿的品牌资产，也不要把生成空间当成真实物业证明。

源码中的实际路径：

| 位置 | 机制 |
| --- | --- |
| `QUIET_FRAME_START` | 全幅主图、墙面中的活文字与摄影外图注；图像通过相对 `src` 加载 |
| `QUIET_CRAFT_START` | 大字与图像阴影的对比取舍、手机文字移出照片、可读的图注尺度 |
| `QUIET_PLAN_START` | 纸面上的日期与选择，避免另起一套卡片产品皮肤 |
| `.plan-time` / `.stay-length` | 已选夜数与完整日期范围成为时间叙事的继续，不是编造指标 |
| `QUIET_PLAN_STATE_START` / `dateValue()` | 唯一日期/房型选择驱动夜数、金额、结果与错误恢复 |

## 交互如何延续同一观念

两个空间把名称与演示单价并列，采用原生 radio；人数只有1/2两个互斥选项，同样直接呈现。这样无需反复打开清单比较两项，也没有为选择增加一组强调卡片。Tab 进入互斥组，方向键使用浏览器原生行为。

快捷夜数根据抵达日更新离开日期。夜数通过 UTC 日差计算，避免时区改变结果；金额只按演示单价乘夜数。选择与估算只保留在当前页面。

无效日期、倒置日期或超过14晚时，错误标记和焦点指向实际字段，保留房型与人数。有效提交生成本页文字计划并把焦点移到结果。它不查询库存、不发送订单、不扣款。

## 迁移与验收边界

适合有空间、光线与具体服务选择的旅宿/生活方式概念。不适合直接替代真实预订、价格或库存系统。已有品牌、图片与组件优先；可以只借照片中的文字关系，或只借时间与计划同源的机制，最多保留一个局部借用点。

更换图片后，重新检查最暗/最亮的实际字形承载区域：普通文字至少4.5:1，大字至少3:1，不以照片平均亮度证明对比。重新看390窄裁切是否仍保有完整空间，并实际操作日期错误、选择、恢复与焦点。两张 PNG 是初始首视口；它们不代表所有状态或新项目已经通过视觉与业务验收。
