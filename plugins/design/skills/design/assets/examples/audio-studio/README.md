# 间频：四秒声音出版

原创离线声音出版概念。四件作品由页面代码本地合成，每件四秒；封面也是本例原创，不是外部艺术家作品、唱片摄影或实时波形。

[页面与完整源码](index.html) · [桌面](desktop.png) · [手机](mobile.png) · [许可](LICENSE)

## 设计哲学与所解问题

采用“让作品先出现，让界面退后”的出版方法。短声音难以被看见；如果首先呈现参数、波形和播放器，观看者容易把作品理解为音频工具。因此先建立一件有身份的声音出版物，再让试听成为靠近作品的一个动作。

这是一项原创设计判断，不是关于某位设计师的史实或权威背书。它的具体命题是：**声音的空隙也有形状。** 主封面的断口、线层和密度围绕这个命题，品牌字标中的间隙与封面呼应；不是为任意产品补上一张通用抽象背景。

## 从哲学到形式规则

- 作品封面承担最大视觉重量。深色声体在纸色页面上形成主体；锈红只作细小断点、当前作品与焦点标记，不把播放器变成另一个主视觉。
- 中文宋体承担作品标题，系统无衬线承担目录和操作，等宽字仅用于编号、时长。标题不是泛用口号，而是当前作品的名字。
- 桌面像出版物的封面与版权页并置。手机先看完整封面，再将标题与试听相邻排布，目录随后出现；没有固定底栏遮住作品或键盘目标。
- 四件封面共享线刻语言，改变折返、疏密、断口和起伏；选择改变作品身份，只有按下试听才发声。

## 素材与代码如何形成效果

所有素材都在 [index.html](index.html) 内，不依赖外链、库、字体文件或音频文件。

- `AUDIO-01: SOUND STAGE`：出版封面、作品信息和相邻控制的比例关系。
- `coverArt()`：确定性路径逐层形成两个分开的声体；每个编号使用对应的形变与线条节奏。它是概念封面，不以实时数据为图像真实性背书。
- `AUDIO-02: TRACK IDENTITY`、`renderTracks()`：四件作品的目录、筛选与当前身份。选中编号、标题和边线共同表达选择。
- `function synthesize(`：正弦、谐波、包络与确定性噪声生成四秒采样。
- `releaseGraph()`、`stopAudio()`：主动停止、自然结束及离页后的声源与上下文释放。

判断形式是否有效时，应在宽窄图里检查：封面的空隙是否仍是主体；标题与当前曲目是否对应；试听是否清楚但不过度抢眼；缩窄后细线是否仍有层次而非仅剩杂纹。源码中改变作品后，应重新看真实图片，不能因算法或这份说明存在就断言图形质量成立。

## 可运行功能

可筛选“氛围 / 律动”、选择作品、主动试听与停止。筛选不会自动换轨，选轨会先停止上一段，也不会自动播放新作品。页面默认不创建音频输出；浏览器确认可以运行后才呈现正在试听，四秒结束不自动续播。

声音经过实际 `AudioBufferSourceNode → GainNode → AnalyserNode → destination` 输出。权限或支持不足时说明没有开始播放；页面隐藏或离开会释放本页资源。界面状态与音频处理可检查，实际听感仍须用自己的设备核对，音频图运行不等于已经通过听音评价。

## 适用、可借与边界

适合独立声音作品、短片段研究、艺术出版及有明确作品身份的媒介探索。可以借“先作品后工具”的层级、系列身份、选中与播放分开、主动试听和可靠释放。

不适合直接作为流媒体、DAW、真实曲库或录音服务。没有远端歌曲、上传、账户、版权音源或声卡录音。不要机械搬走品牌、线刻外形和合成参数；新的声音题材需要自己的视觉观念。接入真实音源时，还需重新定义许可、加载、解码、进度与失败恢复，不能用四秒计时伪装歌曲播放。
