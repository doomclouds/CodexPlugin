# 白纸索引 · 展开的出版目录

[完整页面](index.html) · [桌面首视口](desktop.png) · [手机首视口](mobile.png) · [许可](LICENSE)

八份原创虚构资料及完整短稿组成一册数字索引。资料、署名、年份、版次与篇幅均为本例内容，不代表真实出版物、馆藏或机构背书；声音类条目只有文字，没有音频文件。目录和全文都在本地，不提供售卖或借阅服务。

## 哲学：目录本身就是一份出版物

这套设计把“整理阅读”变成纸面结构：版次、编号、形式、页数和标题先建立一份可查找的书目，再从同一编号进入全文。桌面像展开的对页，手机像一页接着读下去；纸边、折痕和排印属于同一个编辑观念。

这里借的是出版编目的关系，不是大师名字或八张封面卡的外观。纸面是代码绘制的数字隐喻，不是实物摄影、材质测量或可拖动的3D翻页模型。

## 要解决的问题

资料库容易变成重复封面卡墙：看得见图，却难比较编号、版次和资料形式。这个索引把这些具体信息放在稳定列位，点击后读的是同一条记录，退出后仍回原编号。主画面不靠一个巨黑标题或左文右大图建立气氛。

适合独立出版、文化资料、作品编目与带全文的阅读索引。不适合直接承接电商、学术馆藏证明、复杂检索或音频服务；不能把虚构文字换个机构名当真实来源发布。

## 形式规则

- 靛蓝底面承托完整纸面，纸边、中央折痕与对页组织共同表现“展开”；它们不承载操作或掩盖信息。
- 编号、版次、年份、形式与篇幅直接可读，不放进hover。手机条目标题20px，普通信息、操作和元数据至少12px，描述14px；不为把八项挤进首屏缩字。
- 条目没有八种装饰封面。小型格式符号只说明页数或折面，真正身份来自准确标题和元数据；它们不是实体书照片。
- 手机转单页顺序，保留同一编号和类别关系；纸面留白可以随筛选改变，不凭空添加填充资料。
- 正文进入独立阅读面板，延续同一墨色、纸色与字体角色；字形和行长服从阅读，不服从主画面的密度。

## 素材与代码机制

完整实现位于[index.html](index.html)。没有外部图片、字体、CDN或第三方运行库；纸面、页边与格式符号由精确CSS绘制，字体使用本机系统回退。

| 定位 | 机制 | 换内容时保留什么 |
| --- | --- | --- |
| `.paper-object`、`.paper` | 数字纸页、中央折痕、对页和手机单页 | 纸面与索引关系，不强加真实材质承诺 |
| `.catalogue`、`.record-open` | 以稳定编号绑定标题、版次、形式和篇幅 | 准确身份与可比较列位，不按过滤后位置猜对象 |
| `.format-mark` | 克制的页数/折面符号 | 与资料形式相符，不冒充真实封面 |
| `renderIndex()`、`data-filter` | 单选类别与实际数量、条目同时更新 | 一份数据源与准确筛选结果 |
| `openRecord()`、`setExpanded()` | 提要、元数据和完整三段原文来自同一记录 | 不把上一篇状态带入下一篇 |
| `reader`的`close`处理 | 原生弹窗关闭后回到打开它的条目 | 原编号焦点及当前筛选保持 |

源码唯一标记可按需定位：`/* ARCHIVE_LAYOUT_START */`对应索引排印，`<!-- ARCHIVE_INDEX_START -->`对应纸面入口，`// ARCHIVE_INTERACTION_START`对应条目与阅读状态。片段只是部分上下文，按问题读取需要的完整函数，不全量载入其他案例。

## 如何验证自己的改稿

先看实际1440×1000和390×844：纸面与索引是否同一观念，标题/编号/版次是否清楚，手机是否仍能连续阅读，有没有为展示整页而缩小正文。再检查筛选后的留白、阅读面板与焦点。

用真实操作核对全部8项、独立出版001/005/007、城市观察002/004/008、声音记录003/006。逐条打开、展开完整三段，确认标题、提要和正文匹配；收起或关闭后按原编号回焦，Escape保持当前类别。重开从提要开始，不把上一次展开状态带入。减少动态偏好应关闭文字过渡。

## 取舍边界

可以借元数据层次、对页到单页的关系、完整阅读和焦点返回。不要照搬虚构事实、靛蓝配色或出版隐喻；其他行业可能需要直接列表、搜索或不同素材。更换资料时同步`records`、分类计数、范围和全文，不只换标题。两张PNG仅展示初始首视口；数据完整、语法合法和图片尺寸都不能自动证明视觉成立。
