# 一公里步行路上的热与荫 · 中文编辑专题

[阅读完整案例](index.html) · [桌面画面](desktop.png) · [手机画面](mobile.png) · [概念影像](street-light.png) · [许可](LICENSE)

这是一份原创示例报道：完整四段论证、三段路线、三个时段、原始表格与方法边界。报道和数据均为构造，不是实际城市采样。街道影像由内置imagegen原创生成，是概念视觉，不是现场摄影或数据来源。阅读时保留整个案例目录，HTML会以相对路径加载影像。

## 哲学：让形式承担报道主张

“有树”与“有一条连续的荫路”不是同一件事。这个专题先让读者感知阳光和树荫的边界，再把一个平均数放回行人的路径。大尺度的“热/荫”、跨版街道影像、等待断点与固定尺度证据，共同表达这一个问题。

这不是某位设计师的官方作品或背书。采用的是内容驱动的出版方法：先确定可讨论的具体主张，再分配观看顺序；标题、摄影式视觉与数字分别承担表达、感知和论证，互不冒充。

## 要解决的问题

原始材料既有空间关系，也有平均数、方法和限制。若首屏只放教学地图，会先暴露分析结构而失去题材感；若只做漂亮封面，又可能让概念图被当作真实证据。因此先建立街道阅读的情境，进入正文后再依次展示差异、证据、方法与行动，并明确构造身份。

适合中文长篇专题、编辑报道、机构洞察与有具体论证的研究阅读。不要直接套到高频工作台、结账表单或只有几句口号的宣传页；也不要用该例的虚构差值替真实研究补结论。

## 形式规则

- **先建立一个视觉重心。** 标题中的“热”与“荫”承担对比，右侧短句说清主张；下方影像横跨版心，不再与一块解释面板平分屏幕。
- **影像表达感知，图表表达数值。** 封面不叠测量点、伪比例尺或温度标签。概念身份放在实色图注中，正文证据另用固定单位和尺度。
- **排印按角色分工。** 系统宋体承担展示与连续阅读，无衬线承担导航、图注与方法，等宽仅承担时刻和数值。中文正文不继承展示标题的紧字距；引语用均衡断行避免孤短尾行。
- **色彩回应内容。** 深绿关联荫部与连续路径，纸色承载阅读，深红和灰绿用于稳定的路线系列；切换时段不改变系列身份。这里不是对图像进行仪器式取色，也不是所有主题都应沿用这组颜色。
- **手机重新取景。** 标题、主张与影像形成纵向封面，影像铺到屏边并重新选择裁切，保留行人和光影边界。正文目录、表格和旁注按阅读顺序展开，不缩成桌面截图。

## 素材与代码机制

完整实现位于[index.html](index.html)，唯一运行时文件依赖是本目录的[street-light.png](street-light.png)，没有远端字体、CDN或运行库。

| 入口 | 机制 | 换内容时保留什么 |
| --- | --- | --- |
| `.story-heading`、`.title-big` | 展示字与主张建立尺度关系，独立设置字距、行高与窄屏尺寸 | 先保留内容主次，不复制同样字数与字号 |
| `.image-stage`、`.cover-image img` | 实际本地影像与响应式`object-position` | 重看主体、光线与裁切；换题材时必须换相应素材 |
| `.cover-image figcaption` | 图注位于实体纸面，避免亮路面上的白字弱对比 | 素材身份、图像主张与阅读对比 |
| `.reading-layout`、`.toc`、`.margin-notes` | 正文、定位与补充信息职责分开 | 完整论证与可回到具体章节的入口 |
| `.evidence`、`.bar-row`、`const values=` | 三时段同一25–40°C尺度，差值随数组计算 | 单位、基线、系列身份及原始值一致 |
| `.method-box`、`#sources` | 方法作为有编号的编辑注释，而非教学卡片 | 指标定义、局限与不能推断的内容 |

目录能定位真实章节；时段按钮更新数值和描述性差值；原始数据可以展开。字号控件在16–22px之间调整，手机正文在此基础减1px；到达边界后对应按钮禁用。阅读标记只保留当前页面，刷新清除，不连接账户或云端。减少动态偏好关闭平滑滚动和柱条过渡。

## 如何验证自己的改稿

先在实际1440×1000与390×844查看封面：能否先读到题材和主张，人物/光影裁切是否仍成立，图注是否完整、对比是否稳定。再滚动检查正文、引语、图表、表格和方法；不要仅看缩略图判断文字质量。

实际操作三时段、展开数据、字号上下限、标记与目录，并读回正确路线和内容。切换时段应保持25–40°C尺度，差值分别为1.1/2.4/0.7°C。它们只描述本例构造数据，不是降温百分比、因果估计、热舒适标准或健康阈值。两张PNG仅展示初始首视口，不证明全部交互与平台都已验收。

## 取舍边界

可以借出版层级、概念影像与证据分工、固定尺度比较和长文节奏。不要整套移植品牌、影像、颜色与虚构数据。没有空间关系的材料应撤掉街道隐喻；只有一项发现时减少章节和旁注。系统字体会随平台变化，重要标题和长正文必须在目标环境重新看图；源码和素材都存在，也不等于视觉判断自动通过。
