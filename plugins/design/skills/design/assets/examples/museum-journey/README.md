# 观物：器与未尽之处

原创概念展览与三章交互导览。主素材、文字、排印和路径均在本案例包中；影像由内置图像生成制作，不是真实文物、现场摄影或工艺考据。源码 `index.html` 与 `media/echo-study.png` 一起使用。

## 设计哲学与问题

本例的原创立场是：**留白也是形体，观看需要次序。** 问题不是怎样把一个对象放进漂亮卡片，而是如何让观察者从整体轮廓走进空隙，再靠近表面。借鉴策展中对象与空间的关系、出版中主图与阅读速度的关系，不将某个工作室名字作为品质背书。

## 方法论：从立场到画面

1. 让贯通的空处成为母题。器形的内部空间与页面文字周围的负空间共同组织观看，不用额外装饰填满。
2. 对象在暗场中近乎充满主画面，光线说明厚度与纹理；展示字位于相对安静区域，避免切过器形。字面与光影各有角色。
3. 将观看分成轮廓、留白、表面三章；每章同时改变叙述、图像裁切、当前站与键盘焦点，交互继续讲述同一观念。
4. 手机重新安排刊头、字面、器形与入口，保留物体的比例和空间，而非缩小桌面并排版。

## 如何做出相似效果

- 使用一张有足够材质、受控照明、可留出文字空间的实际图像。确认来源与概念身份；不要用低精度形体代替需要质感的主视觉。
- `.hero` 是完整画幅，图像用 `object-fit` 与有意裁切承载主体；标题保持真实文字。深浅与对比根据图像上文字实际经过的区域核对。
- 展示字使用衬线角色，正文/操作使用清楚的无衬线角色；具体系统字体回退由环境决定，不能把声明当作已加载证据。
- 观察图像通过 `data-view` 切换实际缩放和取景原点。`selectChapter` 同步图像、完整内容、标签、进度和下一站。减少动态偏好取消缩放过渡。
- 一个方向统一图像、文字、间距与交互；不要额外套入另一套色板或卡片语言。

## 操作与检查

点击章节或使用左右方向键、Home、End；“下一站”会循环并将焦点移到对应章。检查实际选中章、正文、取景与进度是否一致。三章内容独立完整。图像变化不代表真实空间漫游。

在宽窄主画面检查物体与字面是否各自完整，标题对比至少3:1、普通文字至少4.5:1；核对实际背景与字体角色。再看三章状态和全页：观察节奏应成立，细节不能退回普通教程卡片。功能检查与视觉判断分别进行，不以截图存在或作者自评宣布优秀。

## 适用、借鉴与边界

适合单对象策展、文化专题、工艺观念与需要慢下来的观看体验。可借鉴对象/负空间/阅读次序的关系，以及章状态同步的实现。

不适合高频工作台或多对象快速排查。不要照搬器形、暗金色或标题作为任意品牌皮肤。实际机构须使用自己的真实作品、出处与访问信息；这里没有真实馆藏、展期或票务承诺。
