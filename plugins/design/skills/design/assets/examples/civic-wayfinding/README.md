# 河岸文化馆：建筑平面与公共导向

[完整页面与源码](index.html) · [桌面主画面](desktop.png) · [手机主画面](mobile.png) · [许可](LICENSE)

这是原创公共文化空间的导向概念。场所、建筑、距离与时间均为构造示例，不对应真实地点，不是实测平面、无障碍认证或现场通行保证。所有图形、文字与交互在单个 HTML 内，无图片、字体、地图 SDK 或远端服务依赖。

## 哲学与所解问题

公共导向应让人同时理解空间、目的地和下一步行动。这里以建筑平面和公共标识建立秩序：墙线、开口与庭院说明场所，字母连接地图和索引，朱红只标明当前选择及路径。图形承担可核对的方向关系，不以复杂立体插画或算法节点代替空间认识。

这是本例作者的设计推导。它解决的是陌生访客从同一入口寻找展览、阅读、服务和体验空间，同时保留无台阶要求的问题；不能从示意图推断真实建筑或通行条件。

## 方法与形式

蓝色河岸构成明确边界，纸色建筑与浅色开放空间区分用途，深蓝负责文字和结构，朱红负责行动。建筑开口朝向关联路径，细线只补充墙体、书架、铺地或入口关系。地图中的 B—G 与索引、选中建筑、路线摘要保持同一身份。

宽屏把地图与目的地、当前路线并置。读者先认入口，再选场所，随后沿同一图中的路径核对步骤。手机裁掉外围空域和重复英文图签，保留完整入口、目的地与连接，重排为地图、两列目的地、当前路线；不把宽屏缩成一张不可读的缩略图。

普通操作和元数据至少12px，主体说明14px，场所标题和字母有独立角色。SVG 标注按实际缩放后的尺寸检查，而不只读源码中的字号；字母与名称也不能只靠颜色对应。建筑不是点击命中区，选择通过有完整名称和键盘焦点的目的地按钮完成。

## 从形式到代码

- `CIVIC-01: WAYFINDING STRUCTURE`：地图、目的地和路线的宽窄组织、控件与状态样式。
- `CIVIC-02: ORIGINAL SPACE MAP`：地图的图形层次、建筑与路径表达。
- `.map-room[data-facility]`：原创建筑轮廓与场所标签，选中状态直接跟随目的地；没有外部图块。
- `points`、`edges`：七个点、八条连接，以及构造距离和通道类型。
- `findRoute()`：按当前条件排除台阶或维护中的坡道，再比较允许连接的距离。
- `mapTrace()`：地图路径使用同一连接；右侧台阶绕过建筑，不能穿过封闭房间。
- `renderRoute()`：一个选择同步建筑、字母、路径、距离、逐段文字与无路恢复。
- `sizeMap()`：窄屏改变真实 SVG 视框，保留同一几何和路线模型。

先按需要读相应片段，再核对完整上下文。改场所布局时必须一起改实际点位、连接、建筑开口和标注，不能只换馆名与房间名称。

## 可验收的行为与效果

默认仅用无台阶路径去展厅为125米、3段；允许台阶时为100米。保持无台阶要求并开启坡道维护，应清除旧线与旧指标、明确无路，并保留选择和条件。用“取消维护条件”恢复125米，焦点回到维护条件。选择体验工坊为155米、4段。不要在无路时悄悄放弃用户要求。

实际查看宽窄主图及全部路线：房间、开口、字母和当前线不能互相遮挡，路径不得穿过封闭建筑；地图缩放后标注仍应可读。操作目的地、复选框、键盘与恢复，核对图形和文字一起变化、焦点完整露出、无整页横向溢出。截图只展示初始状态，不能代替新场所的通行和操作验收。

## 迁移边界

可以借用空间与行动的并置、跨图与索引的同一身份、平面图的主次以及保留约束的恢复机制。适合文化场所、园区、展馆的概念导向。既有机构视觉优先，只借适用机制，不把整套色板当成统一模板。

真实部署需要准确场地资料、维护状态、实测距离及现场无障碍核验。本例没有定位、真实比例、实时封路或服务连接；不得把构造平面和距离直接用于现场引导。
