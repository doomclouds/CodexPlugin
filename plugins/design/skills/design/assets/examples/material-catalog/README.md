完整离线目录包括 `index.html` 与 `media/surface-study.png`。保留两者的相对目录即可打开。木、毡与矿物板是原创概念材质视觉，由内置图像生成能力制作；不是供应商实拍、实测样品、材料认证或真实商品。代码、文案与概念素材按本目录 MIT 许可提供，字体使用系统回退。

## 哲学与问题

材料先被表面、边缘与接触关系感知，之后才被规格解释。这是本例作者的设计立场，不是借用某位大师的名义。要解决的问题是：如何让目录同时支持感知与核对，又不把材料降成参数记录，或把美丽照片误当尺寸证据。

方法是分开两种观看：先用一组有重量、纤维和颗粒的静物陈列建立触感，再让同一对象的编号与数据带人进入共同尺度。摄影与几何有各自的职责，不能互相替代。

## 立场怎样成为形式

宽屏按材料专刊的跨页阅读：左侧陈列占主要面积，右侧“表面／之下”错位字面、短行说明与三项观察索引形成旁页。木层、纤维与颗粒的不同截面真实进入画面，标题不是给任意行业加一句标语。

纸灰 `#f1f0eb` 与近黑 `#262820` 保留物体的颜色；泥红 `#8a3d30` 只标当前对象与行动。展示字宽屏80px、手机57px，正文14px，图注、编号和功能说明至少12px。等宽字体只给共同单位与参数，不将所有信息做成微型工程标注。

手机先读刊头与主题，再看保留三种材料关系的裁切，随后选择对象。选择索引保持编号、文字、下划线与焦点，不只靠颜色。下方是连续规格阅读与比较，采用纸面、短行、共同列，不再制造一套属性检查器。

## 怎样制作相似质感

先确定要观察的表面与边缘，再制作静物图。可迁移的图像提示关系：

> 原创材料专刊的编辑静物摄影；层积木暴露薄层边缘、深灰纤维毡折过接触面、浅色细颗粒矿物板；三者形成有重量的建筑式组合；单一方向光、可信接触阴影与微纹理；无工具、花瓶、标记、尺寸或网页元素。

图像中的物体尺度不承担下面的数值结论。更换材质时，应重新制作与该材质有关的表面、边缘和光线，不能把所有物体统一换色后称为不同材料。

| 源码位置 | 实现机制 |
| --- | --- |
| `MATERIAL_COVER_START` | 陈列与旁页的跨页结构、字面关系和手机重排 |
| `MATERIAL_COVER_VIEW` | 实际媒体相对路径、图注、主题与可键盘选择的索引 |
| `MATERIAL_LEDGER_START` | 从触感到规格的过渡、连续条件与共享对照列 |
| `geometry()` | 同一单位、角度与投影规则生成比较几何；不读取照片像素 |
| `selectSample()` / `renderComparison()` | 对象身份、参数、容量、移除与焦点来自同一组数据 |

## 真正可操作的目录

三份样例的设计参数分别为240×160×12、240×160×8、300×200×10毫米。选择或方向键、Home、End 改变当前对象与规格；不会把概念图冒充新的实拍样品。

最多保留两份进行比较。几何使用共同投影与缩放，同维度的数值留在可读表格中；300与240的长宽比例保持1.25。第三份不会挤掉已有选择，而是明确提示先移除；移除保留当前材料，焦点回到可继续的加入操作。颜色只帮助对象辨别，不是材质检测结果。

## 可借与不可搬

适合材料专刊、器物目录、工艺观察和共同条件的比较。可借“触感先行／精确核对随后”或“身份与共享维度同源”的一个机制，保留用户自己的品牌、素材与组件。

不适合直接承担采购、生产、施工或性能判断；厚度差不能推出强度、重量或寿命。真实选型需要实际来源、规格、试样与使用条件。更换内容后，重新看物体品质、中文尺度、窄裁切和比较阅读，再执行上限、移除和键盘状态。两张 PNG 仅是初始首视口，不证明未捕获的全部状态或新项目已经验收。
